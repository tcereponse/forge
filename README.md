# Forge

> **A comprehensive web development platform** — combining a Next.js toolkit with modular mini-services for rapid application building.

---

## 🚀 Quick Start

```bash
# Install dependencies
bun install

# Start development server
bun run dev
```

The app runs at **http://localhost:3000** by default.

---

## 📦 What's Included

| Directory | Purpose |
|-----------|---------|
| `src/` | Next.js application source code (App Router) |
| `apps/` | Standalone utility and example applications |
| `skills/` | Modular skill-based AI integration components |
| `mini-services/` | Lightweight microservice implementations |
| `mobile-app/` | Capacitor-based mobile app (Android APK) |
| `prisma/` | Database schema and migrations |
| `public/` | Static assets |
| `db/` | Database configuration and seeds |
| `data/` | Data files and configurations |
| `docs/` | Documentation resources |
| `examples/` | Usage examples |

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 14+](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + [shadcn/ui](https://ui.shadcn.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Package Manager**: [Bun](https://bun.sh/)
- **Database**: [Prisma](https://www.prisma.io/) ORM
- **Mobile**: [Capacitor](https://capacitorjs.com/) (Android APK builds)
