# 💎 EXTENSION : MULTI-AGENT ORCHESTRATION
## 🤖 PROTOCOLE D'INTELLIGENCE COLLECTIVE

Cette extension définit les schémas de collaboration entre les différents agents de la Forge.

### 1. PATTERNS MULTI-AGENTS
- **Orchestrateur Suprême** : Centralisation de la vision stratégique et répartition des tâches atomiques.
- **Continuité de Session** : Transfert systématique des contextes clés (Text > Brain) pour éviter la dégradation de la mémoire.
- **Parallélisation** : Exécution simultanée des modules indépendants (ex: Build Client vs Build Server).

### 2. COMPRESSION DE CONTEXTE (ELITE COMPRESSION)
- **Synthèse de Mission** : Réduction des logs verbeux en instructions actionnables.
- **Omission Sélective** : Priorisation des fichiers de configuration et des schémas de données sur le code boilerplate.
- **Ancrages Sémantiques** : Utilisation de mots-clés uniques pour rappeler des blocs de code complexes.

### 3. SOUVERAINETÉ DE L'INFORMATION
- **Archivage SYSTÉMATIQUE** : Chaque décision technique doit être consignée dans le `.brain` ou les SOP.
