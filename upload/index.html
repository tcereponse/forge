Installation

  1. Crée un dossier kirov-extension-vercel sur ton PC
  2. Télécharge les 5 fichiers ci-dessus dans ce dossier
  3. Ouvre Chrome → va sur chrome://extensions/
  4. Active le Mode développeur (en haut à droite)
  5. Clique "Charger l'extension non empaquetée"
  6. Sélectionne le dossier kirov-extension-vercel
  7. L'extension est installée ! 🎉
